# User-Supplied Bermuda Sprite Sources

These 64×64 sprites were supplied by the user for the first Bermuda Triangle card batch. They are used unchanged in the game. The two supplied Cannonball Ray images were identical, so one source and one playable card are retained.

The batch contains Anchor Crab, Shipwreck Moray, Chain Catshark, Rust Lobster, Compass Jelly, Cannonball Ray, Bilge Eel, Figurehead Fish, Ghost Net, Mimic Chest, Skeleton Fisherman, Bottomless Maw, Lightning Marlin, Thunder Jelly, and Squall Crab.

The second batch adds Drowned Diver, Buoy Jelly, Bonefish, Ghost Ship, Void Angler, Phantom Shark, Living Whirlpool, Abyssal Spadefish, Mobius Eel, Tempest Seahorse, Stormfin Tuna, and Stormback Whale.
