# User-supplied Open Ocean sprites

These 64×64 transparent sprites were supplied directly by the user. Preserve their pixels and palette; do not add eyes or redraw details.

All game-facing creatures point right. The Whale Shark, Paper Nautilus, Emperor Penguin, and Atlantic Puffin sources pointed left, so only their shipped game assets are horizontally mirrored. The archived sources remain unchanged and carry the `-left-facing` suffix.
